## Abstract:

In this talk we discuss that the set of $d$-copulas, $d\in\mathbb{N}$, is a bounded, closed, convex and compact subset of $L^p([0,1]^{d})$, $p\in[1,\infty)$.
This mirrors the situation when embedding the set of copulas into the Banach space of continuous functions on $[0,1]^{d}$ equipped with the norm of uniform convergence.
When focusing on $L^2([0,1]^{d})$, this specifically implies that any point in $L^2([0,1]^{d})$ admits a best approximation by a \emph{unique} copula.
We discuss numerical methods to approximate this copula and take care that it is possible to draw pseudo-random realisations from the resulting approximations at each step. 
The results are applied to provide an $L^2$ optimal antithetic sampling algorithm that is shown to improve the standard antithetic variable method.

This talk is based on joint work with Bernard Colin (Université de Sherbrooke) and Charles Truax (Université de Sherbrooke).
